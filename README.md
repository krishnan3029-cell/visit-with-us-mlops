# Visit with Us - Tourism Purchase Prediction

This application predicts customer purchase propensity using
a Random Forest classification model.

## Features
- Customer information input
- Purchase probability prediction
- Marketing outreach recommendation

## Technology
- Python
- Scikit-learn
- Streamlit
- Docker
- GitHub Actions
- MLflow

## Source Repository
https://github.com/krishnan3029-cell/visit-with-us-mlops

## Disclaimer
The model predicts general tourism purchase propensity
using historical data. It is not specifically validated
for Wellness Tourism Package purchases.
